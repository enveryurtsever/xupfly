# Contributing to XUPFLY

Thank you for your interest in contributing to **XUPFLY**!

## How to Contribute

1. **Open an issue first** for major features or architectural changes.
2. **Fork** the repository and create a branch from `main`:
   ```bash
   git checkout -b feat/your-feature
   ```
3. **Keep PRs focused** on a single change and run `npm run lint` and `npm run build` before submitting.
4. **Never commit secrets** (`.env*`, API keys, OAuth tokens, or database dumps).
